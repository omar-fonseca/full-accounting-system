## Flujo recomendado

Una feature debe partir de una base actualizada, recibir cambios pequeños, pruebas y documentación, y abrir una revisión antes de integrarse a `main`. Los commits deben explicar intención y conservar el historial como evidencia, no como sustituto de pruebas.

## Aprendizaje

Git registra evolución; GitHub hospeda y coordina colaboración. Ninguno demuestra por sí mismo que una funcionalidad funciona: esa afirmación requiere pruebas y evidencia de ejecución.
